## [1.0.0] — 2026-10-06

### Added
- Full hybrid microservices architecture (Java Spring Cloud + .NET 8 + Angular 18+)
- AI-powered CV semantic analysis via SharpAPI with deterministic compatibility scoring engine
- Automated PDF generation for conventions (QuestPDF) with digital signature support
- Mid-term and final evaluation workflow with official PDF attestation generation
- Real-time SignalR notification hub with transactional HTML email templates (STB branding)
- Rotating JWT refresh token authentication with secure password reset flow
- Granular RBAC: ADMIN, TRAINER, LEARNER with strict per-role data scoping
- Asynchronous event bus via RabbitMQ + MassTransit (11 typed event contracts)
- Full audit log for all sensitive administrative actions
- Kubernetes manifests: Deployments, Services, HPA, Ingress, ConfigMaps, Secrets
- Docker Compose multi-container local stack (10 services)
- GitHub Actions CI pipeline: Java (Maven), .NET 8, Angular, integration tests
- Prometheus + Grafana monitoring configuration
- Nginx production config with optional TLS
- Comprehensive smoke test scripts (PowerShell + Bash + Node.js)

### Changed
- Repository renamed from `gestion-des-stagiere` to `STB-stageconnect`
- Default branch renamed from `gestion-des-stagiere` to `main`
- README rewritten: bilingual (English primary, French secondary), professional badge header, Mermaid architecture diagram
